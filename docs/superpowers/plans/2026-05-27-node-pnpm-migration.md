# Node pnpm Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fully migrate the repo from Bun to Node 24 LTS and pnpm.

**Architecture:** Keep TanStack Start, Vite, Drizzle, and local SQLite. Replace Bun-specific runtime boundaries with Node equivalents: `better-sqlite3` for SQLite, Vitest for tests, `tsx` for TypeScript scripts, and `node:fs/promises` for filesystem work.

**Tech Stack:** Node 24 LTS, pnpm 10.29.3, TanStack Start, Vite, Drizzle ORM, better-sqlite3, Vitest, tsx.

- [x] **Step 1: Convert Scryfall file cache**

In `src/utils/scryfallFileCache.ts`, import Node filesystem helpers and replace Bun APIs:

```ts
import { mkdir, readFile, writeFile } from "node:fs/promises";
import { dirname } from "node:path";

```

Use this `loadCache` body:

```ts
private async loadCache() {
    try {
        const content = await readFile(this.filePath, "utf8");
        const cachedCards = JSON.parse(content) as ScryfallCard[];
        for (const card of cachedCards) {
            const normalizedName = normalizeCardName(card.name);
            this.cacheData.set(normalizedName, card);
        }
        this.isCacheLoaded = true;
    } catch (error) {
        if (error instanceof Error && "code" in error && error.code === "ENOENT") {
            return;
        }
        throw error;
    }
}
```

Use this write section in `set`:

```ts
await mkdir(dirname(this.filePath), { recursive: true });
const content = JSON.stringify(Array.from(this.cacheData.values()), null, 2);
await writeFile(this.filePath, content);
```
