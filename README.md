# mtg-keyword-codex

## Requirements

- Node 24 LTS
- pnpm 10.29.3 via Corepack or Volta

The package manager is pinned in `package.json`.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Verification

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Database

```bash
pnpm db:generate
pnpm db:migrate
```
